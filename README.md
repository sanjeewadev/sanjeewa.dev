# sanjeewa.dev

Personal portfolio website for Sanjeewa Vipula Kumara.

## Stack
- Next.js App Router
- React
- JavaScript
- Traditional CSS

## Development
```bash
npm install
npm run dev
```

Open http://localhost:3000.

This project is the clean Next.js migration of the previous Astro website, preserving its design, content, SEO structure, and interactions.
